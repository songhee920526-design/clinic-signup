# 금요일 클리닉 신청

유리한 수 수학교습소 — 학원 운영 툴과 완전히 별개인 사이트.

- 학생 화면: `/` (이름 + 희망 등원 시간 버튼, 인원수만 표시)
- 원장님 화면: `/admin.html` (PIN 필요: 정원 조절, 마감, 클리닉 없음, 명단 삭제·추가)
- 한 주 = 금요일 저녁 7시 ~ 다음 금요일 저녁 7시(한국 시간). 7시가 지나면 다음 주 금요일 빈 명단으로 자동 전환, 지난 명단은 기록으로 남음
- 저장소: Netlify Blobs(`clinic`), 학원 운영 툴 데이터와 무관
- 테스트: `cd tests && npm install && npm test`
